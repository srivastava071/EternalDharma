## 🏛️ Core Features & Architecture

### 1. Interactive Hero Digital Sanctuary Deck
- **Real-Time Emotional Dilemma Mirror:** Select your current mental state (*"Anxious"*, *"Torn by Duty"*, *"Searching for Meaning"*, *"Powerless"*) to dynamically morph Sanskrit calligraphy and reflection guidance.
- **Ambient Soundscape Bar:** Live background Himalayan river and temple chanting audio controller with animated equalizer visuals.

### 2. "Ask the Gita" Real-Time Dilemma Oracle
- Client-side NLP matching engine allowing seekers to input life struggles (*"career failure"*, *"anger"*, *"grief"*, *"loneliness"*, *"overthinking"*) and receive Krishna’s exact counsel, Sanskrit verses, actionable Sadhana practices, and Karma XP rewards.

### 3. Procedural Web Audio API Resonance Engine
- Zero external audio library dependencies.
- Synthesizes **528Hz Tibetan Singing Bowl chimes** and **432Hz Om drones** with exponential gain decay envelopes.

### 4. 24-Hour Dincharya (Vedic Circadian Rhythm) Clock
- Senses the user's live local time and highlights the active Vedic cycle (*Brahma Muhurta*, *Praataha*, *Madhyahna*, *Sandhya*, *Nishi*) with personalized mindfulness recommendations.

### 5. Atmospheric Mode Switcher (Suryodaya Dawn / Sandhya Cosmic Night)
- Ethereal theme toggle smoothly morphing the entire palette between radiant Himalayan sunrise parchment and deep indigo cosmic night with golden accents.

### 6. 3D Sacred Pilgrimage Darshan Portals (*Tirtha Yatra*)
- 3D interactive darshan cards for **Kedarnath Mahadev (432Hz)**, **Kashi Vishwanath (528Hz)**, **Tirupati Balaji (580Hz)**, and **Dwarkadhish Kingdom (650Hz)** with interactive temple bells and Darshan XP.

### 7. Gamified Sacred Sadhana Profile & Karma XP Engine
- Interactive progression engine tracking reflection streaks, saved verses, and Karma XP ranks (*Jijnasu &rarr; Abhyasi &rarr; Sadhaka &rarr; Jnani*).
- Features daily rate-limiting (XP can only be earned once per action per day), persistent local state, multi-user profile switching, and 1-click sign-out.

### 8. Bonus Round: Easter Egg Unlocked
- **Konami Code (`↑ ↑ ↓ ↓ ← → ← → B A`)** & **5-tap brand emblem trigger** revealing the immortal *Pavamana Mantra (Brihadaranyaka Upanishad 1.3.28)* with `+108 Karma XP`.

## 🛠️ Technology Stack

- **Markup:** Semantic HTML5 (ARIA landmarks, accessible dialogs, clean heading hierarchy)
- **Styling:** Modern CSS3 (Custom Design System tokens, Fluid typography via `clamp()`, Glassmorphism, 3D CSS Transforms, 100% Responsive with 0px horizontal overflow)
- **Scripting:** Modular Vanilla ES6+ JavaScript (Zero external dependencies)
- **Audio:** Web Audio API Procedural Synthesis + HTML5 Audio Element Dock
